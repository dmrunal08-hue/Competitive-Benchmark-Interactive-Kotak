# Competitive Benchmark: Interactive Radar (Kotak Neo)

Single-file interactive radar chart comparing nine investing apps on five UX parameters (scored 1-5).

- Open `index.html` in a browser. No build step.
- Hover a product to focus it, click to pin it.
- Scores and brand colours live in the `DATA` array in the script. Brand colours are approximations.
- Body text uses the locally installed *Test Geograph* font and falls back to Inter. The font file is not included.
